# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Once the repository is published on GitHub, report vulnerabilities through GitHub's private vulnerability reporting ("Security" tab, "Report a vulnerability"). Include steps to reproduce, the affected version or commit, and the expected impact.

Until the repository is published, there is no public reporting channel. Do not post vulnerability details anywhere public.

## Scope

CartDE handles customer contact details and order data for stores its users run. Reports about authorisation bypass, data exposure, unauthenticated setup or reset, and upload handling are treated as high priority.

## Supported versions

CartDE has no released versions yet. Security fixes will land on the main branch until the first release.

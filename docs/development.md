# Development

## Setup

Requirements: Node.js 22.16 or newer, pnpm 11.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

The scaffold created `.env` with a generated `EMDASH_ENCRYPTION_KEY`. If `.env` is missing, copy `.env.example` to `.env` and set that key. Do not commit `.env`.

Open http://localhost:4321/_emdash/admin. The first visit runs the EmDash setup wizard. The first account created is the administrator, and it uses a passkey.

## Checks

```bash
pnpm typecheck
pnpm build
pnpm wrangler deploy --dry-run --outdir dist/worker-dry-run
```

These are the same checks CI runs. Automated tests are not yet written; the first tests arrive with milestone 0.2.

## Generated files

- `emdash-env.d.ts` is regenerated by the dev server. Do not edit it by hand.
- `worker-configuration.d.ts` is generated by Wrangler.
- `.emdash/migrations.json` is generated by the build and is ignored by git.

## Upgrading EmDash

EmDash is pinned to an exact version in `package.json` and the lockfile. Upgrade in a dedicated pull request, read the EmDash changelog, and run all checks.
